uConnect Desktop 0.1.0 beta

Start
-----
Windows: extract the entire ZIP, then run uConnect.exe.
macOS (Apple silicon): extract the ZIP, then open uConnect.app. The app is
  not notarized, so macOS blocks the first launch: choose Open Anyway under
  System Settings > Privacy & Security, or run
  xattr -dr com.apple.quarantine uConnect.app
Linux: run the AppImage (chmod +x first), or extract the .tar.gz and run
  AppRun in its folder. Needs Ubuntu 24.04 or a distribution as new.
Each package includes its Qt runtime; nothing else needs installing.
These are beta builds without publisher signing or Apple notarization.

uConnect keeps running in the system tray (the menu bar on macOS) when its
window is closed; open it again or exit from the tray icon. Settings >
Connection can start it when you sign in, and turn the tray off.

Connect your devices
--------------------
1. Use the same reachable rendezvous server (host:port) on every device.
2. Create a New Topic on one device and privately share its Copy Link.
3. Paste that link on the other devices and Connect.
4. Verify the device fingerprints and trust the other devices.
Each device then chooses what the others may do in their permissions.

Services
--------
Storage: offer folders under Settings > Services > Storage; trusted devices
  browse, download and upload as their permissions allow. Downloads go to
  the folder set there.
Folder sync: keep a folder the same on several devices (Sync window).
Screen, remote control and camera: requests show a consent prompt on the
  sharing device; stop with the sharing bar or Ctrl+Alt+Shift+S. macOS
  needs Screen Recording and Accessibility; Wayland is view-only.
Extended display: a Windows or macOS device can use another device's screen
  as an extra monitor (any desktop can be the display). On Windows this
  installs the bundled display driver once, with administrator approval;
  until the driver has a release signature, Windows also asks whether to
  trust its publisher. Best on the same local network.

The package includes the rendezvous server (uconnect-rendezvous): run your
own with it, as SERVER.txt describes.
View > Debug Window (Ctrl+Shift+D) shows the connection state and log.
Report problems with that log and the steps that led to them.
